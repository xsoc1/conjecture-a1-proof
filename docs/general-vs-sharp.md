# 一般性、最优性与形式化范围

## 主定理

K 为特征零域，V 任意维，Z=XY−YX，XZ=ZX、YZ=ZY。
对任意非负整数 p、q，若 X^(p+1)v=Y^(q+1)v=0，则 (X+Y)^(2p+2q+1)v=0。

修正后的书面证明还给出更强结论：Heisenberg 万能代数中每个加权次数
a+b+2k≥2p+2q+1 的 X^aY^bZ^k 都属于左理想 AX^(p+1)+AY^(q+1)。
这里的左理想不能当作双边理想；原来的两个归纳系数错误与模值多项式消去说明已局部修正。
独立审稿和逐项修正记录见 `audit-2026-11-05/`。

## 最优性

`sharpness.md` 与报告最优性一节给出 `(W*)^⊗p ⊗ W^⊗q` 上的显式模型，W=K³。
它对每一对参数都满足假设，且第 2p+2q 次幂非零。因此一般一致最小指数恰为
2p+2q+1。该结论有一般性书面证明；49 例精确计算是另列的一致性检查。

若额外有 XY=YX，则界为 p+q+1，且对交换模型最优。其他“Z 低阶幂零就严格降低指数”
的旧稿表述缺少明确界和证明，本次撤回。原文应用的三类参数为 p=0、q=0 或 p=q=1；
不能将其改述为 p、q 均属于 {0,1}，也不能据此断言单个参数为零时只需指数 3。

## 形式化

主定理的书面证明、一般最优性的书面证明、有限计算和 Lean 编译是四种不同证据。
Lean 中目标的 `def` 只定义命题，不证明命题；更强中心假设或元素幂零版本也不等于原猜想。
实际已编译声明、版本、标准公理及未完成义务以 `../formalization/PROGRESS.md`
与 `formalization-notes.md` 为准。本次允许交付范围明确的部分形式化。
